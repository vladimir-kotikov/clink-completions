## 2026-07-02

### 新增 ls/cp/mv/rm 命令补全
- 创建了 4 个 Unix 基础命令的 Clink Tab 补全文件
- 每个命令包含根文件 (`.lua`) 和懒加载包装 (`completions/.lua`)
- **ls.lua**: 目录补全 + 常用 flag (-l, -a, -h, -r, -t, -S, -R, -1, -F, --color, --help, --version)
- **cp.lua**: 文件补全 + 常用 flag (-r, -f, -i, -n, -v, -u, -p, -a, -l, -s, -T, -t DIR, --help, --version)
- **mv.lua**: 文件补全 + 常用 flag (-f, -i, -n, -v, -u, -T, -t DIR, --help, --version)
- **rm.lua**: 文件补全 + 常用 flag (-r, -f, -i, -v, -d, --one-file-system, --no-preserve-root, --help, --version)
- 使用 `matchers.dirs` (ls) 和 `matchers.files` (cp/mv/rm) 做路径补全
- 遵循项目现有的 defer_completions 懒加载模式

### 升级 ls/cp/mv/rm 补全：API 迁移 + 中文描述
- 从旧式 `defer.register_parser()` API 迁移到 `clink.argmatcher()` API（与 fd、less、curl 一致）
- 每个 flag 都加上了 `:adddescriptions()` 中文说明，按 Tab 时可以看到参数含义
- ls: 新增 -d/-i/-L/-p/-s/-X/-U/-v/-c/-u 等 flag，共 26 个带描述的 flag
- cp: 新增 -b/-d/-P/--parents/--strip-trailing-slashes，共 21 个带描述的 flag
- mv: 新增 -b/--strip-trailing-slashes，共 12 个带描述的 flag
- rm: 新增 -I/--interactive/--preserve-root，共 12 个带描述的 flag
- 删除了旧的根 .lua 文件，现在只保留 completions/ 下的实现（与 fd/less/curl 同模式）
- 将所有描述改为英文
